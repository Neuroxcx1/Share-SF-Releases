# Share SF — descargas

Usa tu teléfono Android como pantalla de tu PC con Windows por cable USB: duplicada o como
pantalla secundaria, con sonido del PC en el teléfono y el micrófono del teléfono en Windows.

## Descargar

- **Windows:** [ShareSF.exe](https://github.com/Neuroxcx1/Share-SF-Releases/releases/latest/download/ShareSF.exe)
- **Android:** [ShareSF.apk](https://github.com/Neuroxcx1/Share-SF-Releases/releases/latest/download/ShareSF.apk)

Todas las versiones están en [Releases](https://github.com/Neuroxcx1/Share-SF-Releases/releases).

## Versión de prueba

- La conexión por cable necesita la depuración USB activada en el teléfono y `adb` instalado en el PC.
- El programa aún no lleva firma digital, por lo que Windows puede mostrar una advertencia al abrirlo.
